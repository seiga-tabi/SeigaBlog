# riot-dev-update 작성 규칙

Riot 공식 개발자 업데이트를 읽기 쉽게 요약한다.

## 필수 입력

- `source_url`
- `source_title`
- `source_published_at`
- `last_checked`
- `official_announcements`
- `confirmed_changes`
- `planned_changes`
- `undecided_topics`
- `release_schedule`
- `related_posts`

## 구분 규칙

- 발표됨: Riot이 확정해서 발표한 내용
- 개발 중: 적용 예정이지만 세부가 바뀔 수 있는 내용
- 검토 중: 확정되지 않은 내용
- 해석: 일반 유저에게 미칠 수 있는 영향

Riot이 확정하지 않은 날짜를 확정일처럼 쓰지 않는다.

# system-guide 작성 규칙

아이템, 룬, 시야, 랭크, 포지션 퀘스트 등 시스템 변경을 설명한다.

## 필수 입력

- `system_name`
- `applicable_patch`
- `official_changes`
- `before_state`
- `after_state`
- `affected_positions`
- `affected_champions`
- `examples`
- `source_notes`

## 금지

- `affected_champions`가 입력에 없으면 영향을 받는 챔피언을 만들지 않는다.
- 입력 예시에 없는 상황을 실제 플레이 예시처럼 추가하지 않는다.
- 공식 변경과 운영 팁을 분리한다.

# Riot 관련 준수 체크리스트

Riot Games 관련 콘텐츠는 비공식 팬/정보 프로젝트임을 명확히 표시한다.

## 필수 확인

- Riot 또는 League of Legends 공식 사이트로 오인될 디자인을 사용하지 않는다.
- Riot 공식 로고를 사이트 로고처럼 사용하지 않는다.
- 도메인에 Riot 상표를 부적절하게 사용하지 않는다.
- 공식 패치노트를 단순 복사하지 않는다.
- Riot 콘텐츠에 독창적인 분석, 비교, 정리 또는 시각화를 추가한다.
- 도박, 베팅, 계정 거래, 부스팅 콘텐츠를 만들지 않는다.
- Riot API 키를 공개 저장소에 기록하지 않는다.
- API를 사용하는 경우 프로젝트 등록 상태를 확인한다.
- Data Dragon 이미지에는 적절한 출처와 법적 고지를 표시한다.
- API 및 자산 관련 정책 변경을 정기적으로 확인한다.

## 등록 상태가 비어 있을 때

`RIOT_PRODUCT_REGISTRATION_STATUS`가 비어 있으면 API 기반 데이터 수익화 준비 상태는 미완료로 표시한다. 공식 패치노트와 공개 정적 자료 기반 글 생성은 계속할 수 있지만, 등록이 완료됐다고 허위 표시하지 않는다.

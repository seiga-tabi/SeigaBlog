# AdSense 운영 원칙

AdSense는 기본적으로 비활성화한다. 승인과 CMP 설정이 끝나기 전에는 광고 스크립트나 빈 광고 컨테이너를 렌더링하지 않는다.

## 금지

- 광고 클릭을 유도하는 문구
- 광고 클릭률을 인위적으로 올리는 기능
- placeholder publisher ID 사용
- 정책 페이지, 404, 초안, 루머 단독 페이지 광고
- 버튼, 언어 전환, 북마크, 챔피언 카드 클릭 영역 근처 광고

## 허용 위치

1. 글의 핵심 요약 다음
2. 충분한 본문이 존재하는 경우 중간 섹션 사이
3. 본문 종료 후 관련 글 앞 또는 뒤

## CLS 방지

광고 슬롯에는 최소 높이를 예약한다. `ADSENSE_ENABLED=false` 또는 `_data/monetization.yml`의 승인 조건이 충족되지 않으면 슬롯을 렌더링하지 않는다.

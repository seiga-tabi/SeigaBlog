# LoL 콘텐츠 클러스터 전략

SeigaBlog는 리그 오브 레전드 전문 블로그로 운영하며 낮은 가치의 글을 대량 생성하지 않는다. 의미 있는 새 정보가 없으면 새 글 대신 내부 리포트를 만든다.

## 콘텐츠 클러스터

| 클러스터 | 목적 | 생성 조건 |
|---|---|---|
| 패치 허브 | 공식 패치노트 핵심 정리, 버프·너프 전후표, 시스템 변경 | 공식 패치노트와 Data Dragon 검증 완료 |
| 패치 후속 메타 | 패치 적용 48~96시간 후 데이터 점검 | 승률·픽률·밴률·표본 수·지역·티어·큐·기간이 구조화 입력에 있을 때 |
| 챔피언 집중 분석 | 특정 챔피언 변경점과 사용자 영향 | 공식 변경점과 관련 기존 글 링크가 있을 때 |
| 시스템·복귀 사용자 가이드 | 아이템, 룬, 시야, 랭크, 포지션 시스템 | 시간이 지나도 검색 가치가 남는 주제일 때 |
| 개발 예정·PBE·팩트체크 | 공식 예정, PBE, 보도, 루머 구분 | 정보 상태가 제목과 본문 상단에 명확히 표시될 때 |

## 주제 점수

```text
사용자 문제 해결 가치: 0~25
출처 신뢰도: 0~20
기존 검색 결과 대비 독창적 가치: 0~20
콘텐츠 클러스터 적합성: 0~10
최신성: 0~10
내부 링크 연결 가능성: 0~10
양언어 작성 품질: 0~5
총점: 100
```

- 85점 이상: 글 생성 PR 가능
- 70~84점: 내부 초안 또는 기존 글 보강
- 70점 미만: 생성하지 않음

이 점수는 Google이나 광고 플랫폼의 공식 점수가 아니라 내부 운영 점수다.

## 공개 글의 독창적 가치

모든 공개 글은 다음 요소 중 2개 이상을 포함해야 한다.

- 변경 전후 비교표
- 이전 패치와의 비교
- 원본 데이터를 이용한 자체 차트
- 포지션별 영향 매트릭스
- 사용자 유형별 행동 체크리스트
- 공식 발표와 실제 데이터 비교
- 변경 이력 타임라인
- 추천과 주의 조건을 함께 표시한 표
- 기존 글을 연결한 주제 허브
- 잘못 이해하기 쉬운 부분의 팩트체크
